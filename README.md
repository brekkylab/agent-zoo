# Agent Zoo

A zoo of agents built on top of [brekkylab/ailoy](https://github.com/brekkylab/ailoy) and
[brekkylab/cortex](https://github.com/brekkylab/cortex).

Each agent lives in its own directory with everything it needs — prompts, tools,
configuration, and its own `README.md`. This file is the table of contents.

## Agents

| Agent | Description |
| --- | --- |
| [Company Analysis](./company_analysis) | An AI agent that runs corporate due diligence and supply-chain risk investigation over a data lake |
| [Headhunter](./headhunter) | An AI agent that turns a job description into a shortlist and cold mails over an SQL talent pool |
