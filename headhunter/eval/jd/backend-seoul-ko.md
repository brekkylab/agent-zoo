# 서버 개발자 (Rust) — 서울

## 회사

물류 스타트업입니다. 배송 추적 시스템의 이벤트 처리량이 1년 사이 12배가 됐고, 지금
구조로는 다음 성수기를 못 넘깁니다.

## 하시게 될 일

- 이벤트 수집·전달 계층을 Rust 로 재작성
- 분산 환경에서 배송 상태가 순서대로, 한 번만 반영되도록 만드는 일
- PostgreSQL 스키마 재설계. 추적 테이블이 단일 인스턴스 한계에 있습니다

## 필수

- **Rust 실무 경험** — 운영 중인 서비스를 Rust 로 만들어 본 것
- **실경력 4년 이상** — 재직 기간이 겹치면 중복을 제외한 실제 기간으로 봅니다
- **서울 근무**

## 우대

- 분산 시스템에서 멱등성·재시도를 직접 설계한 경험
- Kafka 또는 유사 메시지 큐 운영

## 채용 방식

상위 3명에게 InMail 을 보냅니다.

**연락은 후보의 프로필 언어로 씁니다.** 한국어 프로필인 분께 영어로 보내지 마십시오 —
회신율이 그것으로 갈립니다.
