# 서버 개발자 (Rust) — 결제 정산 플랫폼

## 회사

Kestrelbank. 국내 이커머스·핀테크 사업자에게 정산 인프라를 제공합니다. 하루 처리
건수가 3년 사이 40배가 됐고, 정산 배치가 마감 시간을 넘기는 일이 분기마다 반복되고
있습니다. 이 자리는 그 배치를 다시 만드는 일입니다.

## 하시게 될 일

- 정산 배치 파이프라인을 Rust 로 재작성. 현재는 Python + Celery 이고 단일 마감
  윈도우 안에 들어오지 못합니다
- 이벤트 수집 계층의 재처리 설계. 중복 정산이 한 건이라도 나가면 안 되므로
  멱등성과 오프셋 관리가 이 일의 중심입니다
- PostgreSQL 파티셔닝·읽기 복제 구성. 정산 테이블이 단일 인스턴스 한계에 있습니다

## 필수 (must-have)

- **Rust 실무 경험** — 취미나 학습이 아니라 운영 중인 서비스를 Rust 로 만들어 본 것
- **실경력 4년 이상** — 재직 기간이 겹치는 경우 중복을 제외한 실제 기간으로 봅니다
- **수도권 근무 가능** — 서울 오피스, 주 3일 출근

## 우대

- 분산 시스템에서 장애 조치·재시도·멱등성을 직접 설계한 경험
- Kafka 기반 스트리밍 파이프라인 운영
- 정산·결제 도메인

## 채용 방식

상위 3명에게 InMail 을 보냅니다. 회신율이 낮은 채널이므로, 왜 이 사람에게
보내는지가 메일 안에 구체적으로 드러나야 합니다.
